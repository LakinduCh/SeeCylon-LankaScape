# SeeCeylon-LankaScape

An interactive 3D tourism web application exploring Sri Lanka's iconic landmarks and wildlife sanctuaries, built with React, Vite, Three.js / React Three Fiber, Tailwind CSS, and Web Audio.

## Features

- **3D Interactive Map**: Powered by Three.js & React Three Fiber with custom terrain models, location markers, and camera controls (Bird's-Eye View and Free Cam).
- **Two-Tier Hierarchical Taxonomy**: Filter destinations by categories (Wildlife, Heritage, Nature, Coastal) and subcategories.
- **Rich Destination Experiences**: Individual destination pages and interactive cards featuring high-definition photo galleries, video previews, ambient soundscapes, and narration audio.
- **Responsive Layout**: Designed for seamless experience across mobile, tablet, desktop, and ultra-high-resolution (2K/4K) displays.

## Getting Started

In the project directory, you can run:

### `npm start` or `npm run dev`

Runs the app in development mode using Vite.\
Open [http://localhost:5173](http://localhost:5173) (or your configured local port) to view it in your browser.

### `npm run build`

Builds the app for production to the `dist` folder.

### `npm run preview`

Locally previews the production build.
